# 0.5.0

Initial native R edition following the published Python 0.5.0 Golden Source:
399 granular calculations, versioned parameters and correlation resources,
synthetic reference cases, local curve adapters, context-local numeric overrides,
dependency-graph calculations and nine reporting interfaces. Includes R help
pages, runnable examples, an introductory vignette and offline documentation.
